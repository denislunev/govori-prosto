# Говори просто — Speak Simply

Бесплатное браузерное приложение для тренировки простой разговорной английской речи для русскоязычных.

**Открыть:** см. ссылку в разделе About справа (GitHub Pages).

## Что внутри

- **Лестница**: курс живого повседневного американского английского. Один урок — одна разговорная конструкция (I'm…, I need…, Can I…?), 12 слов и 10 фраз. Шаги урока: слова → формула → фразы → говорение → тест. Следующий урок открывается при 85% в тесте, после каждых 5 уроков идёт марафон на 50 фраз. Есть банк ошибок и резервная копия прогресса в файл.
- **500 полезных слов** в 20 блоках по 25 по 10 темам: разговорные слова, чувства, люди и характер, описание вещей, общение, действия, работа и деньги, время и привычки, быт и магазин, дорога и здоровье.
- Каждое слово дано в **короткой простой фразе** (до 8 слов) с переводом.
- **Слушай и повторяй**: озвучка обычная и медленная.
- **Скажи с русского**: видишь русскую фразу и говоришь по-английски, приложение проверяет сказанное.
- **Интервальные повторы**: трудные фразы возвращаются завтра, лёгкие через 1, 3, 7, 21 и 60 дней.
- **Тренажёр «Упрости»**: длинная русская мысль → 3–6 простых английских слов.
- Без рекламы, регистрации, очков и серий.

## Установка на телефон

Открой ссылку в Chrome → меню (три точки) → «Добавить на главный экран».

## Требования

- Голосовая проверка: Chrome на компьютере или Android. На iPhone голосовая проверка работает только в Safari и только если не добавлять приложение на главный экран.
- Без голоса (озвучка + ввод текстом) приложение работает в любом современном браузере.
